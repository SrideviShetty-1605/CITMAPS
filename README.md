# CITMAPS – Smart Indoor Navigation System

### Making indoor navigation simple, interactive, and accessible.

## About the Project

CITMAPS is an interactive indoor navigation platform designed to help users navigate complex buildings such as colleges, hospitals, malls, and commercial spaces.

Unlike traditional navigation systems that primarily focus on outdoor locations, CITMAPS focuses on indoor spaces by providing interactive maps, location search, route visualization, and 3D building exploration.

## Key Features

- Interactive indoor maps and building layouts.
- Search for rooms, departments, and facilities.
- Route visualization for easy navigation.
- 3D indoor map visualization.
- Recent search history.
- Simple and user-friendly interface.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **3D Visualization:** Three.js
- **Backend:** PHP, Node.js
- **Database:** MySQL
- **Data Management:** JSON

## How It Works

Users can explore the building map, search for a destination, and view the suggested navigation route to reach their location.

## Future Scope

- Multi-floor indoor navigation.
- Real-time positioning and navigation.
- Support for multiple buildings and institutions.
- Mobile application integration.
- Smart navigation recommendations.

## Vision

To make indoor navigation as simple as outdoor navigation by creating an accessible and scalable platform that can be adapted to different buildings and environments.
