# CITmaps

Run the frontend through a local web server so the JSON files can be loaded.

## Quick start

1. Open PowerShell in `E:\CITmaps`
2. Run:

```powershell
.\start.cmd
```

3. Open [http://127.0.0.1:8080](http://127.0.0.1:8080) in your browser

Press `Ctrl+C` in the terminal to stop the server.

## Alternate command

If you prefer not to use the launcher:

```powershell
cd E:\CITmaps\frontend
node server.js
```
